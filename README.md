# Giri Prasad, portfolio

Senior Product Designer. Live at https://giriprasadux.github.io/

Next.js, exported as static files for GitHub Pages.

```
npm install
npm run dev     # http://localhost:3000
npm run build   # static site in out/
```

`main` holds the source and `gh-pages` holds the built site. To use a custom domain, build with
`NEXT_PUBLIC_SITE_URL` set to the domain.
